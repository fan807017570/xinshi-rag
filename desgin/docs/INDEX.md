# xinshi-rag 设计文档索引

## 文档说明

本文档集基于当前仓库代码、配置文件和 Docker Compose 文件整理。代码是事实来源；若本文档与代码不一致，应以代码为准。输出目录按需求使用 `desgin/docs`。

当前文档覆盖目标：

- RAG 问答链路：多轮指代消解、查询改写、向量检索、分数过滤、角色过滤、BGE 重排、提示词组装、DeepSeek 生成。
- 微信交互链路：URL 校验、AES 加解密、XML/JSON 报文、异步客服消息、access_token 缓存、限容量队列与超载提示。
- HTTP 接口、文档上传与索引重建、Milvus 基础设施及两种部署方式。
- 实现级类图、配置、数据结构、异常与当前实现边界。
