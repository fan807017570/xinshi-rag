# 2026年江西省上饶市初中学业水平考试（中考）报名工作指南

根据江西省教育考试院印发《关于做好2026年江西省初中学业水平考试（中考）报名工作的通知》（赣考院中〔2026〕1号）精神，结合上饶市实际制定本指南。

## 一、报考类别

### 初三年级考生
报考分为两类：
- 普通高中类
- 中职类（含高等职业院校、普通中等专业学校、职业高中、技工学校）

报考类别经考生网上报名并信息确认后，不得修改。

### 初二年级考生
初二年级考生不分报考类别。

## 二、报名条件

### （一）初三年级考生

1. **基本报名资格**  
   具有上饶市初中学籍或户籍（截至2026年2月28日，以家庭为单位的居民户籍3年内未办理户籍迁移手续）的应届和历届初中毕业生均可报名。  
   学校或其他单位集体户籍、投靠亲属户籍、与户主无亲属关系户籍等不作为初中学业水平考试报名的户籍依据。  
   应届初中毕业生必须参加初中学业水平考试。

2. **普通高中均衡招生志愿报考条件**  
   - 只限于在籍直升应届初中毕业生（学籍在本校，且初一至初三年级均在本校学习的应届初中毕业生，含按规定正常转学和休学的学生）。  
   - 在本县（市、区）内初三年级期间从城区学校转入农村初中或城区内其他学校的考生不属于正常转学，不得认定均衡生资格。  
   - 历届初中毕业生可以报考普通高中（含省级重点高中），但不能填报省级重点高中和省级重点建设高中的均衡志愿。

3. **市外就读回户籍地录取**  
   具有上饶市户籍，在外省、本省外市完成义务教育的学生：
   - 可回户籍地参加初中学业水平考试并录取；
   - 也可在就读地报考，办理高一学籍后转学到户籍所在地对应层次的普通高中；
   - 或提供考试所在地考试机构出具的可录取相应层次普通高中证明（含当地初中学考满分值及每学科成绩），到户籍所在地教育考试机构办理转录手续。  
   办理转录的考生户籍必须以家庭为单位的居民户籍，且3年内未办理户籍迁移手续；集体户籍、投靠亲属户籍等不作为办理普通高中转录的户籍依据。

4. **本市外县就读回户籍地录取**  
   具有上饶市户籍，在本市外县完成义务教育的学生，如要求回户籍地录取高中，则必须回户籍地报考，否则不得录取到户籍地所辖普通高中（含民办）。

5. **进城务工人员子女和随迁子女**  
   - 可在户籍地或学籍地报考，在报考地录取；
   - 户籍和学籍均不在上饶市的，只能在户籍地或学籍地参加考试，在报考地录取并办理高一学籍后转学到父母工作地所对应层次的普通高中。

### （二）初二年级考生

1. **基本报名资格**  
   具有上饶市初中学籍或户籍（截至2026年2月28日，以家庭为单位的居民户籍2年内未办理户籍迁移手续）的在读初二年级学生。  
   集体户籍、投靠亲属户籍等不作为报名户籍依据。

2. **地理、生物考试规定**  
   - 具有上饶市户籍，在外省接受义务教育的学生：地理、生物（含实验操作）需回户籍地参加补考报名及考试。  
   - 在本省外市完成义务教育的学生：需提供就读初中学校所在地设区市教育考试机构（加盖公章）出具的成绩证明材料（不含等级证明）；没有成绩证明的考生必须参加2026年初二年级地理、生物补考。  
   - 进城务工人员子女和随迁子女可在就读学校报名参加地理和生物学科考试。

3. **考试次数限制**  
   应届（含正常休学的）初中毕业生在中考前只能参加一次地理、生物的报名及考试，成绩计入当年初中学考总成绩（缺考考生按0分计入）。  
   历届生必须参加2026年的地理、生物补考。

### （三）不得报名的人员
- 普通高中和中职在籍学生。

## 三、报名方式及时间

- **报名时间**：2026年3月5日9:00 至 3月17日17:00
- **报名方式**：网上报名
- 逾期不予补报。

## 四、报名地点

| 考生类型                     | 报名地点                                                     |
| ---------------------------- | ------------------------------------------------------------ |
| 应届初中毕业生、初二年级学生 | 由学籍学校组织集体报名；回户籍所在地报名的考生须在户籍地教育考试中心指定地点报名 |
| 历届初中毕业生               | 凭初中毕业证书和户籍材料到所在地教育考试中心指定地点报名     |

## 五、报名流程及其他

### （一）报名流程

1. **审查考生报名资格**  
   县(市、区)教育考试中心审查资格，对符合条件者发放报名序号和密码。  
   - 初中学校在校生：在初中学校领取。  
   - 其他考生：到各地教育考试中心指定的报名点领取。

2. **网上报名信息录入及核验二代居民身份证**（3月5日至17日）  
   各报名点登录江西省教育考试院网站（www.jxeea.cn）录入考生报名信息，进行数码拍照。  
   所有初三年级和初二年级考生均须核验二代居民身份证。

3. **网上报名信息确认**（3月18日至23日）  
   考生登录上述网站，核对个人基本信息并确认。

4. **网上签订诚信考试承诺书**  
   考生须认真阅读并签订《考生诚信考试承诺书》。

5. **网上报名缴费**（仅初三年级考生，3月25日至31日）  
   - 每日缴费时段：9:00-21:00  
   - 缴费入口：江西省政务服务统一支付平台（支持支付宝、银联云闪付、江西银行、江西农信社、工商银行、农业银行、建设银行的网银支付）  
   - 逾期未缴费视为自动放弃报考资格，缴费完成后无法退费。  
   - 初二年级考生暂不缴费。

重要提示：居民身份证是初中学业水平考试报名、考试、录取、报到注册的重要身份证明。考生在报名信息确认后到学校新生报到注册期间，不能修改姓名、身份证号、出生年月等关键信息，否则后果由考生本人承担。

### （二）报名收费标准

| 费用项目 | 金额     |
| -------- | -------- |
| 报名费   | 5元/人   |
| 考务费   | 10元/科  |
| 合计     | 105元/人 |

用于命题、制卷、监考、评卷、录取等各项支出。

## 六、工作要求

### （一）强化组织领导
- 各地制定本地报名方案和应急预案。
- 资格审查实行“班主任初审、学籍管理员复核、分管校长总把关、考试中心集中审查与复核”的四级把关机制，各环节签字确认存档，实行“谁审核、谁把关，谁签字、谁负责”的原则。
- 不得限制学生报名，不得剥夺学生参加考试的权利。

### （二）规范信息采集
- 2026年全市采用现场读取二代居民身份证或拍照上传身份证正面的方式采集基本信息。
- 各地须于2026年1月下旬前完成对辖区初二、初三年级考生身份证办理情况摸排，确保考生在2026年2月上旬前完成证件办理。
- 各报名点重点校验姓名、身份证号等关键字段，杜绝错填、漏填、误填。

### （三）加强宣传服务
- 综合运用政务网站、学校公告栏、家长微信群等载体宣传政策。
- 各县区教育考试中心及报名点必须设立咨询窗口，公布咨询电话。
- 重点强化对特殊群体考生（随迁子女、留守儿童等）的服务保障。
